# Cadence releases

Official Windows downloads for Cadence.

See [Releases](https://github.com/Freshxrd/cadence-releases/releases) for installers, update metadata, and SHA-256 checksums.

Current builds are beta testing versions. Features may change and bugs may occur. The Windows installer is unsigned and may trigger a publisher warning.

Release provenance and artifact checksums are recorded in [releases/](releases/).
The source and release repositories use `main` for the released baseline and `dev` for new development.
